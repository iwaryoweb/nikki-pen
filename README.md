# nikki-pen

自分用の日記入力PWA。2フィールド（金・一行）を書いて「記す」を押すと、GitHubのprivateリポジトリ（日記の正本）へ直接コミットする。

- データはこのリポジトリには一切入らない。ここにあるのは皮（UI）だけ
- 認証はFine-grained PAT（対象リポ限定・Contents読み書きのみ）。端末のlocalStorageにのみ保存
- 圏外時はローカルにキューし、次回オンライン起動時に自動送信
- ホスティング: GitHub Pages（静的1ページ）

## セットアップ

1. GitHub Pagesを有効化（Settings → Pages → Deploy from a branch → main / root）
2. iPhoneのSafariでPages URLを開く → 共有 → **ホーム画面に追加**
3. 初回起動時に設定が開くので、Fine-grained PATを貼る

## 送信まわりの挙動（v1.2）

- GitHubがエラーを返したときは理由をトーストで出し、下書きは残す（例: `GitHub 404: nikkiが見えない。PATのRepository accessを確認`）。**圏外（通信自体が失敗）のときだけ**キューに入れる
- 起動時・復帰時・オンライン復帰時に未送信分を再送する。失敗したら理由を出す
- 新しい版は起動時・復帰時に取り込み、下書きが無ければ自動で読み直す。下書き中なら次回起動で切り替わる
- 鍵は端末のストレージ単位。iOSはSafariとホーム画面アプリで別なので、**ホーム画面アプリの側で**貼る。アイコンを削除→再追加すると消える

## v1スコープ

2フィールド＋保存＋オフラインキューのみ。履歴表示・装飾はv2以降（7日続いてから）。
